# Glide Beyond Obvious — Netlify Easy-to-Update Website

## Deploy to Netlify
1. Go to Netlify and choose **Add new site → Deploy manually** (or drag this entire folder/ZIP into the deploy area).
2. Upload the ZIP/folder containing `index.html`, `images/`, `netlify.toml`, and this README.
3. Netlify will publish `index.html` as the homepage.

## Updating photos or logo
All editable images are in the `images` folder. Replace the image with a new file **using the exact same filename** and redeploy.

- `logo.png` — GBO logo
- `hero-aerial.jpg` — main hero image
- `thermal-inspection.jpg` — thermal inspection feature
- `thermal-solar.jpg` — thermal solar example
- `roof-aerial.jpg` — roof/aerial example
- `construction-aerial.jpg` — construction/site example
- `solar-rgb.jpg` — solar panel RGB image
- `aerial-media.jpg` — aerial media image
- `drone.jpg` — DJI Mavic 3 Enterprise image

## Recommended image rules
Keep the same file type and preferably similar dimensions. JPG is ideal for photographs; PNG is ideal for the logo.

## Updating text
Open `index.html` in a code editor and search for the text you want to change. Your phone, email, address, services and page copy are all in this file.

## Important
This is a static site and does not require a database or server. It is suitable for Netlify hosting.
